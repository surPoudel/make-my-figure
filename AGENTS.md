# Agents in this repository

- **MakeMyFigure Developer** - `.agents/makemyfigure-developer/AGENT.md`. Adds scientific plot types
  (from a name, description, reference image or local paper), integrates them with the whole
  application, validates and documents them, builds a local test app, and stops for author approval.
  Also holds the approved commit / push / release runbook. Model-independent and offline-capable.

Start every task by running `python .agents/makemyfigure-developer/scripts/inspect_registry.py`.
