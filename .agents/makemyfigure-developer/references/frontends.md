# Frontends: desktop (PySide6) and browser (Streamlit)

Reference for the MakeMyFigure developer agent. Written 2026-09-17 against branch
`feature/makemyfigure-developer-agent` (forked from `main` that day). Line numbers are
from that snapshot; re-verify with the greps at the end before relying on them.

Both frontends are thin layers over `make_my_figure_core`. The rule stated in
`docs/DESKTOP_APP.md` ("Architecture", lines 139-152) and enforced by tests: no
plotting logic lives in a GUI file. A GUI reads the registry and `ui_hints`, builds
widgets, assembles a PlotSpec dict, and calls `render`/`export_*` on the core.

## 2. Desktop app (`apps/desktop_app/`)

### Entry point and launch
- Module: `apps/desktop_app/main.py`; `main()` at line 3022, guarded by `if __name__ == "__main__"`.
- Run from source: `python -m pip install -e ".[desktop]"` then `python -m apps.desktop_app.main`
  (also `python apps/desktop_app/main.py`; docs at `docs/DESKTOP_APP.md:74-80`, `README.md:59`).
- Flags: `--selftest` runs `_selftest()` (line 2952) headlessly: for every
  `available_plot_types()` entry it loads the example, builds a spec, renders and exports a
  ZIP, then exercises two statistics paths; `--debug` prints `debug_info_text()` and loads the
  bar-plot example, dumping `diagnose()`, toolbar self-test and widget tree (3036-3052).
- `matplotlib.use("Agg")` is forced at line 20; the figure is drawn headless and embedded in
  `FigureCanvasQTAgg`. Lines 30-70 guard the PySide6 import and print install hints plus the
  Streamlit fallback if Qt cannot load (this is what fires in the Linux/WSL sandbox).
- Frozen builds: `packaging/make_my_figure.spec` (PyInstaller), `packaging/windows_installer.iss`;
  see `docs/BUILD_INSTALLERS.md`.

### How each control area is populated (`_build_workbench`, main.py 401-656)
- Plot-type combo (452-459): first item is `PLOT_TYPE_PLACEHOLDER` with data `None`, then one
  item per `controller.plot_types()`. Item data is the plot-type id; label is `display_name`.
  `currentIndexChanged` -> `_on_plot_type_changed` (2364). The File > Open example menu
  (1216-1220) is built from the same list.
- Style combo (461-463): `controller.styles()`; labels mapped through `STYLE_LABELS` (controller.py 44-46, single "Publication").
- Recommended figures (471-476): `RecommendationsPanel`; filled by `_refresh_recommendations`
  (1618) after data load via `controller.recommend_for_loaded`. "Generate" -> `_apply_recommendation`
  (1629) sets the combo to `rec.plot_type` and applies the draft mapping; "Add to builder"
  additionally calls `action_save_panel`.
- "2. Map columns" (490-492) and "3. Options" (494-496) are empty `QFormLayout`s rebuilt by
  `_rebuild_mapping_and_options` (2138) on every plot-type change / data load:
  - For each `controller.column_fields(pt)`: a `QComboBox` of `_column_options()` ("(none)" +
    columns), defaulted from `default_mapping`, else a prefill guess, else a Matrix-Workflow handoff.
    Multi-column roles (`ui_hints.is_multi_column`) get a `QListWidget` with ExtendedSelection
    (2169-2178). Matrix plot types (module set `_MATRIX_PLOT_TYPES`, 109-116) get an extra
    "Value columns" list widget (2208-2231) seeded by `grouping.value_matrix_columns`.
    PCA metadata roles come from `controller.pca_metadata_fields()` (2233-2245).
  - For each `controller.options(pt)`: `_make_option_widget(opt)` (2290-2329), added as a form row
    with `opt.label` (2250-2253). After that: handoff defaults applied once, then the statistics
    panel's column choosers and advisory suggestions refreshed (2281-2288).
- `_make_option_widget` kind mapping: `bool` -> `QCheckBox`; `choice` -> `QComboBox` of
  `str(choice)`; `number` -> `QDoubleSpinBox` if `decimals > 0` else `QSpinBox`, with
  min/max/step; a `number` with `default=None` is optional: special-value text "(auto)" at the
  minimum and property `mmf_optional=True`. Bool/choice trigger `render_preview` immediately;
  numbers go through the 180 ms debounce timer `_schedule_render` (2331; timer set up at 293-296).
  There is no `text` option kind in `ui_hints.Option`; free text exists only for fixed controls
  (title/labels, network custom-colour JSON in Streamlit).
- Value flow back: `_collect_mapping` (2335-2362) reads every mapping combo ("(none)" -> None),
  the value-column and multi-column list widgets, then each option widget by type; an optional
  spin box at its minimum is omitted. `_build_spec` (2408-2462) merges this with
  `_collect_layout_controls()` (1126) and calls `controller.build_spec` (313), which drops
  `None`/"" values into `spec["mapping"]`, sets `journal_style`, `output`, `layout`,
  `statistics` (normalised) and `source`. Style overrides from `_collect_style_overrides` (1156)
  become `spec["style"]`. Click-to-label picks add `selected_points`/`selected_labels`/`label_offsets`
  to the mapping; a heatmap with "Define groups" output adds `spec["column_annotations"]` (2460).
- Validation: none in the widgets beyond spin-box ranges. Errors surface when
  `controller.render` raises `RenderError`/`SpecValidationError`; `_try_build_and_render` (2464)
  returns them, `render_preview` (2492) clears the stale figure and shows the message in the
  Messages tab; `_on_plot_type_changed` (2364) offers "Use example data for this plot type" when
  uploaded data lacks the required columns.
- "4. Labels & size" (498-522): title/x/y edits, width combo (`default/single/onehalf/double`),
  DPI spin, click-to-label checkbox. Fixed controls, plot-type independent.
- Figure preset group (`_build_preset_panel`, 662-696): combo of `PresetStore().list(pt)` via
  `_refresh_preset_list` (698); Apply/Save/Delete/Import/Export/Reset. Apply and "Open PlotSpec"
  both go through `_apply_spec_to_controls` (863), the single spec -> widgets path (mapping
  combos, list widgets, option widgets by type, labels, style spins, layout, colorbar, statistics).
  Save dialog offers style vs full mode (`extract_preset(..., mode=...)`, 794).
- "5. Publication style" (`_build_style_panel`, 1004-1124): a checkable group; unchecked means
  defaults apply and both collectors return `{}`. Sub-groups Typography (palette from
  `USER_PALETTES`, font, pt sizes, marker, line, spine, grid), Axes & labels (tick angles, pads),
  Legend, Colorbar, Figure margins + auto-fix. Palette and other choices are hard-coded lists
  here, not read from `capabilities.py`; the desktop does not grey out inapplicable controls,
  the render path warns instead (`warn_ignored_style_controls`).
- "6. Statistics" (`StatisticsPanel`, stats_panel.py 88-204): `TEST_CHOICES` built from the core
  `TESTS` registry (46); mode/correction/annotation choices are module constants (47-86).
  `stats_spec()` (255) returns the StatsSpec dict consumed by `controller.build_spec`;
  `load_spec()` (286) is the reverse; `show_report()` (333) fills the results table and method text;
  export buttons call controller `export_stats_table`/`export_method_report`.
- "5. Export" group (546-560): buttons for SVG/PNG/PDF/PlotSpec JSON -> `export_single` (2870),
  "Export all as ZIP" -> `export_zip` (2902, `controller.export_bundle`), "Save template" ->
  `action_save_template` (1421). File stems are sheet-aware via `workbook_io.output_basename` (2863).
- "6. Multi-panel figure" (562-572): `action_save_panel` (1438) deep-copies the current spec +
  DataFrame into `self._saved_panels`; `action_figure_builder` (1457) opens
  `FigureBuilderDialog(controller, saved_panels)` (stats_panel.py 400): ordering, per-panel
  size, fonts, layout presets, external panel import, live preview, "Save figure...".
- Pop-out panels: `PanelManager` registered in `MainWindow.__init__` (339-348) for keys
  `figure`, `data`, `controls`; View menu entries "Pop Out Figure/Data Table/Controls" and
  "Dock All Panels" (1258-1269). `pop_out` reparents the same widget into a `_FloatWindow`;
  geometry persists in `QSettings` (`panel_geo/<key>`).
- Right side: `QTabWidget` with editable data preview (`_populate_table` 1979,
  `_on_table_cell_edited` 2058) and Messages tab; figure container below with Matplotlib
  toolbar (`_show_figure` 2557).

### Does a new plot type need desktop edits?
No, for the baseline. Registering the renderer in `registry._RENDERERS`/`_DISPLAY_NAMES`/
`_DEFAULT_MAPPINGS`, adding `COLUMN_FIELDS`/`OPTIONS` entries in `ui_hints.py`, and adding an
example to `examples/example_data_manifest.json` makes the type appear in the combo, the Open
example menu, the mapping/options forms, the help dialog, and `--selftest`. Desktop places that
name plot types explicitly, and when they matter:
- `main.py:109-116` `_MATRIX_PLOT_TYPES`: add here only if the new plot consumes a features x samples
  matrix and needs the "Value columns" picker.
- `main.py:2155` volcano-only DE column prefill (`_volcano_prefill`, 2024).
- `main.py:2110-2112` and `2124-2133` `_group_value_prefill` GV set: optional profiler-based
  x/y prefill for group-value plots.
- `main.py:2208` PCA uses `matrix_row_id` as its id field (`"matrix_row_id" if pt == "pca_scatter_from_matrix" else "row_id"`).
- `main.py:2460` heatmap-only `column_annotations` injection.
- `main.py:1358`, `3039`, `2985`, `2997`: examples loaded by diagnostics/self-test (not catalogue).
- `controller.py:92` `needs_metadata` compares to `mock_data.PCA_PLOT_TYPE`.
- Style capability rows in `capabilities._CAPS` are generated from renderer source; the
  desktop does not read them, but `tests/test_style_capabilities_audit.py` will fail if the
  generated table drifts, so run `python scripts/audit_style_capabilities.py --write`.

### Does a new plot-specific option need desktop edits?
No. Add an `Option(...)` to `ui_hints.OPTIONS[<plot_type>]`; the renderer reads it from
`spec["mapping"][key]`. The widget is generated by `_make_option_widget`; the value is collected
by `_collect_mapping` into `spec["mapping"]`. Options never reach `spec["style"]`; that block is
only the Publication panel's `_collect_style_overrides`. Give `scope="style"` to visual options so
they travel in style presets (`presets.extract_preset` filters on scope).

## 3. Streamlit app (`apps/streamlit_app/streamlit_app.py`, 1326 lines)

### Launch
`streamlit run apps/streamlit_app/streamlit_app.py` (add `--server.fileWatcherType none` on
cloud-synced folders; `README.md:58`, `docs/CROSS_PLATFORM_UI_QC.md`). No Qt needed. Companion

"Workflow" radio (line 361) is "Matrix workflow (guided)".

### Structure (top-to-bottom script, reruns on every widget change)
- Imports (34-47): `ui_hints`, loaders, workbook, registry (`available_plot_types`,
  `display_name`, `default_mapping`, `make_spec`, `render`), `default_output_block`, style engine, examples.
- `SAMPLE_FILES` (52-70) is a legacy fallback used only when `examples.has_manifest()` is False;
  with the manifest present the "Bundled sample" list is `examples.plot_types_with_examples()` (208).
  `EXTRA_COLUMN_FIELDS` (85-87) appends PCA `color`/`shape`; `column_fields_for()` (90) wraps
  `ui_hints.column_fields`.
- Sidebar: Reset button (112) wipes `st.session_state`; `_clear_sheet_dependent_state` (120)
  drops `map_*`, `valcols_*`, `annot_*`, `mw_*`, `grp_*` keys on sheet switch; staged preset
  values are written into widget keys before any widget exists (`_preset_pending`, 160-163).
- "1. Data" (165): Bundled sample / Upload / Open a saved PlotSpec (171); workbook sheet browser (252-330).
- Main area: editable table (`st.data_editor`, 398), "Define groups" expander (419), "Recommended
  figures" expander (514-546) rendering `recommend_for_table` cards with "Use" buttons that set
  `st.session_state["rec_plot_type"]` and rerun (548).
- "2. Plot type" (552-559): `[PLOT_TYPE_PLACEHOLDER] + list(available_plot_types())`,
  `format_func=display_name`. "3. Style" (561-565): `list_profiles()`.
- "4. Column mapping" (567-633): `mapping = default_mapping(plot_type)` then one
  `st.sidebar.selectbox` per `column_fields_for(plot_type)` keyed `map_<field>`; multi-column roles
  use `st.sidebar.multiselect`; matrix types (`_MATRIX_PLOT_TYPES_EARLY` 584, `_MATRIX_PLOT_TYPES`
  611-613) get a "Value columns (measurements)" multiselect keyed `valcols_<plot_type>`.
- Hand-written per-plot option widgets (637-772), each `if plot_type == ...`: bar/grouped bar
  error (638), heatmap cluster/scale (640-643), volcano cutoffs (644-646), volcano/MA "Label points"
  expander (651), scatter fit (710), box kind/points (712-714), line error (715), ridge overlap
  (717), enrichment top_n (719), stacked sort-by (721), waterfall sort (723), forest reference/log
  (725-727), network edge/node/layout controls (728-772). PCA metadata upload (775-798).
- Figure preset expander (885-955) over `make_my_figure_core.presets`; `_preset_to_session` (824)
  stages values then reruns.
- "5. Publication style" (956-1039): expanders Figure / Typography / Axes & labels / Legend /
  Colorbar; sliders keyed `sty_*`/`lay_*`/`lab_*` with defaults in `_STYLE_DEFAULTS` (804-814)
  seeded into session state. Values build `style_overrides` (-> `spec["style"]`) and
  `_layout_controls` (-> `spec["layout"]`); colorbar keys go into `mapping`.
- Generic registry options (1041-1099): after every hand-written section,
  `_generic_opts = [o for o in ui_hints.options(plot_type) if o.key not in mapping and o.key not in _OPTIONS_OWNED_ELSEWHERE]`
  (1059-1065) renders whatever the hand-written blocks did not: `choice` -> `st.sidebar.selectbox`
  (1071), `bool` -> `st.sidebar.checkbox` (1075), `number` with no default -> `st.sidebar.text_input`
  parsed as float with a warning on bad input (1081-1087), `number` with default ->
  `st.sidebar.number_input` with min/max/step (1096). Keys are `opt_<plot_type>_<key>` so presets
  can set them (guarded by `tests/test_figure_preset_ui_wiring.py:85`).
- Capability note (1101-1106): `warn_ignored_style_controls(plot_type, style_overrides)` shown as a caption.
- "6. Statistics" (1112-1150): hand-built expander; `TESTS` from the core; produces `stats_spec`.
- Placeholder gate (1155-1159): `st.stop()` until a real plot type is chosen.
- Spec assembly (1160-1196): `make_spec(plot_type, table_name, journal_style, mapping=..., layout=..., output=default_output_block(...), source=...)`
  (1184), then `spec["style"] = style_overrides`, `spec["statistics"]` if enabled.
- Render (1229): `render(spec, table_info.dataframe, style=style, aux=render_aux)`; aux is PCA
  metadata, network node table (`if plot_type == "network_graph" and bundled_aux`, 1224) or a
  matrix handoff. `st.pyplot(fig)`, publication check, Publication QC expander, statistics table
  with StatsSpec download, render metadata.
- Export (1287-1313): `st.download_button` for SVG/PNG/PDF via `registry.figure_to_bytes` and a
  PlotSpec JSON sidecar; no ZIP bundle, no Figure Builder, no pop-out panels in the browser app.

### Differences from the desktop
- Layout: everything in `st.sidebar`; preview and exports in the main column. No splitters or
  floating windows; no multi-panel builder.
- State: per-rerun recomputation; persistence only through `st.session_state` keys named above.
  A preset or handoff cannot write into an existing widget, so both stage values and `st.rerun()`.
- Options: Streamlit keeps a hand-written block for the original plot types and relies on the
  generic block for everything else; the desktop is fully generic. If a hand-written widget and a
  registry `Option` share a key, the hand-written one wins (the generic loop skips keys already in
  `mapping`), so label/choices can drift between the two apps for those keys.
- Export: download buttons instead of file dialogs; ZIP bundle is desktop-only.

### Does a new plot type / option need Streamlit edits?
No for a plot type: the selectbox, mapping widgets and generic options all derive from the
registry and `ui_hints`. Places that name plot types explicitly: `SAMPLE_FILES` (52-70,
fallback only), `EXTRA_COLUMN_FIELDS` (85-87), `_MATRIX_PLOT_TYPES_EARLY` (584) and
`_MATRIX_PLOT_TYPES` (611), PCA id field (614), the hand-written option blocks (637-772), PCA
metadata (775), network aux (1224). A new matrix-type plot must be added to both `_MATRIX_*`
sets and to the desktop `_MATRIX_PLOT_TYPES`. No for a new option either, provided the key is not
in `_OPTIONS_OWNED_ELSEWHERE` (1059) and not already set by a hand-written block.

## 6. UI acceptance checklist for a new plot type
Run on a machine with PySide6 (desktop) and in a browser (Streamlit); record in the PR.
1. Load example: desktop File > Open example > <display name> renders without a Messages-tab
   warning; Streamlit "Bundled sample" lists the type and renders. `python -m apps.desktop_app.main --selftest` exits 0.
2. Map columns: every `COLUMN_FIELDS` role appears as a picker with the manifest default
   preselected; multi-column roles show a multi-select; switching to "(none)" on a required role
   produces a validation message, not a stale figure.
3. Options render: every `OPTIONS` entry appears under "3. Options" (desktop) and in the sidebar
   (Streamlit) with the right widget kind and default; changing each one visibly changes the figure;
   optional numbers show "(auto)" / stay blank and are absent from the exported PlotSpec.
4. Statistics toggle: enable, pick "Auto-suggest", Run; either results appear or the advisory
   explains why the plot type has no test; disabling removes annotations.
5. Style/preset: tick "5. Publication style", change palette and a font size, confirm effect or an
   "ignored for this plot" warning consistent with `capabilities.py`; save a style preset, reload
   the example, apply it, confirm values return (both apps).
6. Export: SVG/PNG/PDF and PlotSpec JSON download; desktop ZIP bundle; reopen the PlotSpec via
   File > Open PlotSpec and confirm the controls repopulate (`_apply_spec_to_controls`).
7. Builder panel: "Save current plot as panel", open Figure Builder, confirm preview and Save figure.
8. Pop-out: View > Pop Out Figure, then Dock All Panels; figure survives and re-renders.
