# Statistics example: nonparametric

Two groups with right-skewed (log-normal) data, 20 each.

Design: unpaired, nonparametric. Default: Mann-Whitney U with a rank-biserial effect size. Use this instead of a t-test when normality is doubtful.

Required columns: `group` (categorical), `value` (numeric).

All data are SYNTHETIC (fixed seed) and not real measurements.
