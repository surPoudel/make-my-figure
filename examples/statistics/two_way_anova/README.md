# Statistics example: two_way_anova

Two-factor design: genotype (WT/KO) x treatment (Vehicle/Drug), 8 replicates per cell.

Design: two categorical factors. Default: two-way ANOVA reporting both main effects and their interaction. For within-cell pairwise brackets, switch comparison mode to 'within each x category'.

Required columns: `genotype`, `treatment` (categorical), `expression` (numeric).

All data are SYNTHETIC (fixed seed) and not real measurements.
