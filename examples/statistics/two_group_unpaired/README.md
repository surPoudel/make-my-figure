# Statistics example: two_group_unpaired

Two independent groups (Control vs Treated), ~18 samples each.

Design: unpaired, two-sided. Default test: Welch's t-test (does not assume equal variance). Alternatives: Student's t-test, Mann-Whitney U.

Required columns: `group` (categorical), `response` (numeric).

All data are SYNTHETIC (fixed seed) and not real measurements.
