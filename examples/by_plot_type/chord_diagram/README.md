# Circos-style chord diagram — example data

**Plot type id:** `chord_diagram`

**Scientific use case:** Ligand-receptor interaction counts between cell types drawn as a Circos-style chord diagram: one segment per cell type sized by its total interactions, ribbons sized by the count of each pair, and a compartment band on the outside.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `source_cell`
  - `target_cell`
- **Optional:**
  - `interactions`
  - `compartment`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Circos-style chord diagram**.

## Replace with your own data

One row per link. 'source_cell' and 'target_cell' are the two categories (they share one set); 'interactions' is the link weight (leave the value role unmapped for equal weights); 'compartment' classifies the source category of each row and colours the outer band.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Do not supply a matrix: melt it to one row per source/target pair first.
  - Negative or missing values are not drawn and are counted in the export warnings.
  - A chord diagram summarises flows; it carries no statistical test.
