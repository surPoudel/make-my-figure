# Dose-response curve — example data

**Plot type id:** `dose_response_curve`

**Scientific use case:** Drug dose-response with a 4-parameter logistic fit and EC50/IC50 per group.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `concentration_uM`
  - `viability_pct`
- **Optional:**
  - `drug`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Dose-response curve**.

## Replace with your own data

One row per well/measurement. Dose must be positive (log x-axis). Optionally group by drug/condition. A 4PL curve is fit per group when 'fit' is on; EC50 is reported only when the fit converges.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Dose must be positive (non-positive doses are dropped for the log axis).
  - Provide several dose levels spanning the response so the fit can converge.
