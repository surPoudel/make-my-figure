# Histogram (binned distribution) — example data

**Plot type id:** `histogram_distribution`

**Scientific use case:** Binned counts of one measurement, as separate panels per group or overlaid - shows the distribution's actual shape (modes, gaps, tails) rather than a smoothed curve.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `group`
  - `measurement`
- **Optional:**
  - `cell_id`
  - `replicate`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Histogram (binned distribution)**.

## Replace with your own data

One row per observation. 'measurement' is the numeric value being binned; 'group' is optional and splits it. Bins are always shared across groups so the panels compare.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Do not pre-bin the data - supply the raw values and let the plot count them.
  - With unequal group sizes, overlaid raw counts favour the larger group: set the Y axis to 'percent', or keep separate panels.
