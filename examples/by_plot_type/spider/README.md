# Spider plot (longitudinal change) — example data

**Plot type id:** `spider_plot`

**Scientific use case:** Longitudinal per-patient change over time (e.g. % change in tumor burden), one line per patient.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `patient_id`
  - `week`
  - `pct_change`
- **Optional:**
  - `arm`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Spider plot (longitudinal change)**.

## Replace with your own data

Long format: one row per patient per timepoint. 'time' and 'value' must be numeric. Optionally color by a response/treatment group; set a reference line (default 0%).

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Keep the data long (one row per patient per timepoint), not wide.
  - time and value must be numeric.
