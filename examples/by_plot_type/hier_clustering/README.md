# Hierarchical clustering (heatmap + clusters) — example data

**Plot type id:** `hierarchical_clustering`

**Scientific use case:** Cluster a feature-by-sample matrix into k groups and export the cluster assignment table.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `gene`
  - `<sample columns>`
- **Optional:**
  - (none)

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Hierarchical clustering (heatmap + clusters)**.

## Replace with your own data

First column = row label (gene); other columns are numeric samples. Choose k, scaling, distance metric, and linkage; the cluster assignment is exported as a table.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Keep the first column as labels; every other column must be numeric.
  - Ward linkage requires the euclidean metric.
  - k must be between 2 and the number of clustered objects.
