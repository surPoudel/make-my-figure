# MA plot (differential expression) — example data

**Plot type id:** `ma_plot`

**Scientific use case:** Differential expression: average abundance (A) vs log fold change (M), colored by significance.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `AveExpr`
  - `logFC`
  - `adj.P.Val`
- **Optional:**
  - `gene`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → MA plot (differential expression)**.

## Replace with your own data

One row per gene/feature. Provide average expression (AveExpr/baseMean/logCPM), log fold change (logFC/log2FoldChange), and a p-value/FDR column (read verbatim).

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - p-values must be numeric; they are never recomputed.
  - Column names are auto-detected but can be remapped.
