# Hierarchical clustering dendrogram — example data

**Plot type id:** `hierarchical_dendrogram`

**Scientific use case:** Hierarchical clustering of a feature-by-sample matrix as a standalone dendrogram.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `gene`
  - `<sample columns>`
- **Optional:**
  - (none)

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Hierarchical clustering dendrogram**.

## Replace with your own data

First column = row label (gene). All other columns are numeric samples. Choose linkage (average/complete/single/ward) and whether to cluster rows or columns.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Keep the first column as labels; every other column must be numeric.
  - Ward linkage always uses a Euclidean metric.
