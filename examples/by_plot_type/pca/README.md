# PCA scatter (matrix + metadata) — example data

**Plot type id:** `pca_scatter_from_matrix`

**Scientific use case:** PCA of an expression matrix; samples colored by group and shaped by batch.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `gene`
  - `<sample columns>`
- **Optional:**
  - (none)

## Auxiliary table

This plot also needs `metadata.csv` (sample metadata). Its `sample_id` values must match the sample column names in `data.*`.

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → PCA scatter (matrix + metadata)**.

## Replace with your own data

Provide the matrix (genes x samples) as data, and a metadata table whose 'sample_id' matches the matrix sample column names.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Metadata sample_id values must exactly match the matrix column headers.
