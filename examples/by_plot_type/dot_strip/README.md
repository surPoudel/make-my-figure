# Dot / strip plot — example data

**Plot type id:** `dot_strip_plot`

**Scientific use case:** Show every observation per group with an optional mean/median summary — a readable alternative to a bar plot.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `group`
  - `value`
- **Optional:**
  - `cohort`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Dot / strip plot**.

## Replace with your own data

One row per observation. 'group' is categorical (x); 'value' is numeric (y). Choose the summary overlay (mean/median with SD/SEM/CI) or turn it off.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Give raw observations, not group means.
  - Keep 'group' as text and 'value' as numbers.
