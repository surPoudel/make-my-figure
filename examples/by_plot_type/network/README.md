# Network graph — example data

**Plot type id:** `network_graph`

**Scientific use case:** Interaction / co-expression network: nodes are genes/features, edges are interactions or correlations, colored by module and sized by degree.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `source`
  - `target`
- **Optional:**
  - `weight`
  - `interaction_type`

## Auxiliary table

This plot can use `nodes.csv` (node attributes): a `node` column plus optional `group`/`value` to color and size nodes. This folder also includes alternate inputs: `edge_list.csv`, `node_attributes.csv`, `correlation_network.csv`, and `adjacency_matrix.csv`.

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Network graph**.

## Replace with your own data

Provide an edge list (source, target, optional weight). Add a node-attributes table (nodes.csv) with node, group, value to color/size nodes. Adjacency-matrix and correlation-network modes are also supported (see the folder).

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Keep source/target as node names (text).
  - A correlation network shows association, not a mechanistic interaction.
