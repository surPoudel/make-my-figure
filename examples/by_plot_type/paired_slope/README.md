# Paired dot plot / slopegraph — example data

**Plot type id:** `paired_slopegraph`

**Scientific use case:** Connect matched observations across conditions/timepoints (before/after, repeated measures).

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `subject`
  - `condition`
  - `value`
- **Optional:**
  - `arm`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Paired dot plot / slopegraph**.

## Replace with your own data

Long format: one row per subject per condition. 'subject' matches paired rows; 'condition' is the timepoint (x); 'value' is numeric. Optionally color by group.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Use the same 'subject' id across conditions so lines connect.
  - Keep data long (one row per subject per condition), not wide.
