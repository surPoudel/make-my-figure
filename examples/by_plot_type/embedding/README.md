# UMAP / t-SNE embedding scatter — example data

**Plot type id:** `embedding_scatter`

**Scientific use case:** Single-cell / sample embedding (UMAP or t-SNE) colored by cluster or metadata.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `UMAP_1`
  - `UMAP_2`
- **Optional:**
  - `cell_type`
  - `batch`
  - `n_genes`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → UMAP / t-SNE embedding scatter**.

## Replace with your own data

Upload PRECOMPUTED coordinates (one row per cell/sample). Point color can be a category (cluster/cell type) or a continuous value; the app picks a legend or colorbar. Upload precomputed UMAP/t-SNE coordinates as a table; direct .h5ad/AnnData support is planned for a future version.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Compute UMAP/t-SNE in your analysis tool first — this plots existing coordinates.
  - Coordinate columns must be numeric (e.g. UMAP_1, UMAP_2).
