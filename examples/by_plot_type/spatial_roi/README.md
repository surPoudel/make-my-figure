# Spatial ROI / region outlines

**Synthetic (CC0).** The deposited CRC table carries no polygon geometry, so these outlines are drawn over the same coordinate range as the real section rather than taken from it. The region names are descriptive, not annotations from the source study.

One row per vertex, ordered by `vertex_order`. Importing geometry someone else defined is the supported path; there is no freehand drawing tool, because a reproducible ROI is one that came from a recorded definition.
