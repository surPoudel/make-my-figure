# Swimmer plot — example data

**Plot type id:** `swimmer_plot`

**Scientific use case:** Per-patient treatment/follow-up timelines (oncology), colored by response with event markers.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `patient_id`
  - `end_month`
- **Optional:**
  - `start_month`
  - `duration_month`
  - `event_type`
  - `response`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Swimmer plot**.

## Replace with your own data

One row per patient. Provide an 'end' time (or a 'duration'); 'start' defaults to 0. Optionally add an event-type column (progression/death/response/...) and a group column.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Give an end time OR a duration.
  - Keep event/response labels to a small consistent set.
