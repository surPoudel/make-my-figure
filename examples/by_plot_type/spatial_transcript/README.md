# Spatial transcript map

**Synthetic (CC0), and deliberately so.** The CRC dataset used by the other spatial examples is CODEX — a protein imaging assay with no transcript coordinates — so a 'real' transcript example would have to be fabricated anyway. This one is honestly labelled instead.

6,100 detections across 5 genes, with a `qv` quality score, laid out over the same coordinate range as the real section so the scale feels right.

Dense marks are rasterised inside PDF/SVG while text and axes stay vector. Subsampling never happens on its own.
