# Calibration plot — example data

**Plot type id:** `calibration_plot`

**Scientific use case:** Reliability of a clinical risk model: predicted vs observed probability, binned, with a perfect-calibration diagonal.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `true_label`
  - `predicted_prob`
- **Optional:**
  - (none)

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Calibration plot**.

## Replace with your own data

true_label is 1/0; predicted_prob is the model's probability in [0,1]. Or provide precomputed 'predicted' and 'observed' probability columns.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Predicted probabilities must be between 0 and 1.
  - The Brier score is reported in metadata, not drawn on the figure.
