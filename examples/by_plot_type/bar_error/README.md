# Bar plot with error bars — example data

**Plot type id:** `barplot_with_error_bar`

**Scientific use case:** Compare a mean readout across experimental conditions with replicate error bars.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one replicate/observation for this analysis.

## Columns

- **Required:**
  - `condition`
  - `replicate`
  - `measurement`
- **Optional:**
  - `unit`
  - `experiment_batch`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Bar plot with error bars**.

## Replace with your own data

Keep one row per replicate. Replace the condition labels and measurement values; the app computes the mean and SEM/SD/CI for you.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Do not pre-average — give raw replicate rows.
  - Keep 'condition' as text, 'measurement' as numbers.
