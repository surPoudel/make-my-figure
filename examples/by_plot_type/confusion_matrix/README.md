# Confusion matrix — example data

**Plot type id:** `confusion_matrix`

**Scientific use case:** Classification confusion matrix (binary or multiclass) with optional row/column/total normalization.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `true_label`
  - `predicted_label`
- **Optional:**
  - (none)

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Confusion matrix**.

## Replace with your own data

One row per prediction: the true class and the predicted class. Or provide a precomputed matrix (first column = true label, other columns = predicted classes).

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Use a small, consistent set of class labels.
  - Switch counts vs percentages with the 'normalize' option.
