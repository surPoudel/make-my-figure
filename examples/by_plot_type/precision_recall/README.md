# Precision-recall curve — example data

**Plot type id:** `precision_recall_curve`

**Scientific use case:** Precision vs recall for one or two classifiers on an imbalanced outcome, with average precision (AUPRC).

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one record for this analysis.

## Columns

- **Required:**
  - `true_label`
  - `score_model_a`
- **Optional:**
  - `score_model_b`
  - `cohort`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Precision-recall curve**.

## Replace with your own data

true_label is 1 for the positive class, 0 for negative. Scores are continuous model outputs.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Include both classes (some 1s and some 0s).
  - AUPRC is the average precision; it is computed only from valid labels+scores.
