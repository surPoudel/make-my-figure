# Spatial map (categories)

One row per cell. `x`/`y` are tissue coordinates in micrometres, `cell_type` is the label drawn in colour.

Synthetic data (CC0), generated with seed 42 to resemble a tumour core with an immune rim.

Declare `coordinate_units`; with `arbitrary` units no scale bar is drawn, because a bar would assert a physical length the data does not carry.
