# Box / violin plot with points — example data

**Plot type id:** `boxplot_or_violin_with_points`

**Scientific use case:** Show full distributions per group as box or violin plots with overlaid points.

> ⚠️ **Synthetic data.** This dataset was generated by
> `scripts/generate_example_data.py` (seed 42). It is plausible but NOT real
> and must not be cited as a biological finding. License: CC0-1.0.

## What a row represents

One row = one replicate/observation for this analysis.

## Columns

- **Required:**
  - `sample_id`
  - `group`
  - `value`
- **Optional:**
  - `batch`
  - `sex`

## Files

- `data.csv`, `data.tsv`, `data.xlsx` — the same table in three formats.
- `plotspec.json` — a ready-to-use PlotSpec (plot type, column mapping, style, output).
- Open any of these in the app via **Use example data → Box / violin plot with points**.

## Replace with your own data

One row per sample/observation. Switch box vs violin with the 'kind' option.

Keep the **required column names** above (or remap columns in the app). Column
order does not matter — the app validates by name and type.

## Common mistakes to avoid

  - Use enough samples per group (>=5) for a meaningful distribution.
