# Publication recreation benchmarks

This benchmark proves Make My Figure can produce **scientifically correct,
publication-ready** panels from **real, permissively-licensed public data** — not
only synthetic demo data. Each panel is generated through the app's normal render
path (`make_my_figure_core.plots.registry.render` + the built-in **Publication**
style) and passes scientific + visual QC after ≥2 render/QC iterations.

**13 panels currently pass** across 6 real public datasets and 10 distinct plot
types. See [`reports/V0_6_PUBLICATION_RECREATION_REPORT.md`](reports/V0_6_PUBLICATION_RECREATION_REPORT.md)
and [`reports/benchmark_summary_table.csv`](reports/benchmark_summary_table.csv).

## License & provenance policy (mandatory)

- **Only** CC0 / CC BY / CC BY-SA / public-domain / BSD data is used. Every dataset's
  license + verification is recorded in `datasets/<id>/provenance.json` and
  [`LICENSE_PROVENANCE.md`](LICENSE_PROVENANCE.md).
- **No published figure images are downloaded or stored** (to avoid all figure-copyright
  risk). The "target" of each recreation is a **textual panel description**; QC is
  checklist-based (no image-similarity). `reference_image_stored=false` everywhere.
- Recreations are **publication-grade, scientifically-traceable** — **not exact copies**
  of any published figure, and not official journal reproductions.
- Large raw downloads (`datasets/*/raw/`) and rendered panel figures
  (`recreated_panels/*/figures/`) are **git-ignored** and regenerated by the scripts.
  Committed artifacts: processed CSVs, PlotSpecs/StatsSpecs, QC reports, provenance,
  manifest, and reports.

## Regenerate

```bash
python benchmarks/publication_recreation/scripts/download_benchmark_assets.py   # fetch raw (skips offline)
python benchmarks/publication_recreation/scripts/curate_benchmark_data.py       # raw -> processed CSVs
python benchmarks/publication_recreation/scripts/recreate_panels.py             # render via app + QC + manifest
python benchmarks/publication_recreation/scripts/evaluate_recreations.py        # summary CSV + report
python benchmarks/publication_recreation/scripts/generate_contact_sheets.py     # contact sheet
python benchmarks/publication_recreation/scripts/validate_manifest.py           # assert >=10 pass
```

Tests: `pytest -q tests/test_publication_recreation_*.py -p no:pytest-qt` (network-free).

## Layout

```
manifest.json                     # every panel + provenance + QC status
LICENSE_PROVENANCE.md             # dataset licenses + how each was verified
selected_panels.md                # the panel selection + rationale
scripts/                          # download / curate / recreate / evaluate / contact-sheet / validate
datasets/<id>/                    # provenance.json, README, curation_report, raw/(ignored), processed/
recreated_panels/<id>/            # plotspec.json, statspec.json?, qc/*.md, figures/(ignored)
reports/                          # report, summary CSV, rejected candidates, contact_sheet.png
```
