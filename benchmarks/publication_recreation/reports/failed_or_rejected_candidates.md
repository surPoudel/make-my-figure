# Rejected / limited candidates

Categories deferred because a **clearly-licensed** real dataset could not be verified within scope (recorded as citation-only, NOT counted):

- **Kaplan–Meier survival**: candidate NCCTG lung / GBSG datasets had unclear redistribution licenses; not downloaded (would need a CC0/CC BY survival table).
- **Volcano / MA from a precomputed DE table**: needs a CC0/CC BY differential-results supplementary (verify via Zenodo/Figshare API) — deferred.
- **Manhattan / Q-Q**: needs CC0/CC BY GWAS summary statistics — deferred.
- **Dose-response, enrichment, oncoprint/lollipop, swimmer/spider**: no license-verified public table sourced in scope.

The app supports all of these plot types (see the example gallery); they were not counted here only because a license-clean *real* dataset was not verified.
