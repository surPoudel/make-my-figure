## Notes

- The release body says installers are "attached to this release automatically when
  each per-OS job finishes" — consistent with the workflow and with the asset
  timestamps (01:14-01:18Z, three minutes after publication).
- The bundled Python wheel of this era lacked the runtime resource folders
  (`setup.py` docstring: "Every published wheel had that problem"); no wheel was
  attached to v1.0.0, so users installed from source.
- `docs/RELEASE_NOTES_v1.0.0.md` still carries the header "Status: v1.0.0 release
  candidate (`1.0.0rc1`)"; it was not updated for the final tag.
