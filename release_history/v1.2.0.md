## Major changes

- Six spatial plot types on a shared spatial core: `spatial_categorical_map`,
  `spatial_composition_map`, `spatial_feature_map`, `spatial_roi_map`,
  `spatial_transcript_map`, `neighborhood_enrichment_matrix`. Validated against
  published results — CNTools Fig 3A reproduced exactly plus an independent
  hand-check importing no project code; Janesick 2023 Xenium Fig 3l reproduced
  and Visium Fig 2c normalisation recovered.
- One typography system shared by every renderer, and one font setting producing
  one size on the page in every panel of a composite figure.
- A requested figure width is final: **225 of 225** plot-type × width
  combinations exact. Three separate layers used to overrule it.
- Error-bar statistics with explicit choices (sem, sd, ci95, ci95_t, iqr), and a
  whisker that does not describe its bar is corrected and reported.
- Experimental publication presets — opt-in, off by default, read-only, style
  only, no journal-compliance or endorsement claim.
- Cluster-bar controls, group separators and label sides on the clustered heatmap;
  the Figure Builder usable at a normal window size (minimum height 902 px → 136 px).

## Known limitations

1. **The macOS `.dmg` is arm64 only.** It was built on an Apple-silicon runner;
   this release provides no x86_64 macOS build, and the README install table does
   not say so. An Intel Mac user would download it and find it does not run, with
   nothing explaining why. Documented behaviour of the build (`macos-build.md`),
   but an undocumented limitation for the user — worth a line in the README.
2. **Windows and macOS were not validated interactively.** Each platform's app was
   built and smoke-tested on its own runner, but no person launched the Windows or
   macOS build, clicked through it and exported a figure before publication. Linux
   additionally had its `xcb` plugin exercised under a virtual display.
3. **The experimental publication presets have had no user testing.**
   `MANUAL_PRESET_ACCEPTANCE.md` is not signed off. They ship opt-in and off by
   default; no number measured during that work should be quoted until it has been
   regenerated on this released build.
4. **Twenty-one places across twelve renderers clamp a derived font size to a fixed
   floor** the figure-wide type scale cannot reach, so a small figure can show mixed
   sizes within one panel — a 60 × 45 mm volcano draws its subtitle at 9 pt beside
   5.8 pt body text. Eight plot types affected. Legible, not uniform.
5. **Six plot types draw overlapping text in their bundled example.**
   `stacked_bar_composition` is over-constrained rather than mislaid out: 30 category
   labels get 7.3 px each and need 15 px at 10 pt because the outside key takes half
   of a pinned 110 mm canvas. The other five have a 3–8 px overlap where the leftmost
   x tick meets the lowest y tick. All six are unchanged from v1.1.1, measured with
   the same instrument.
6. **`Node.js 20` deprecation** warnings on `actions/checkout@v4` and
   `actions/setup-python@v5`; not failing, but the pins will need raising.

## Follow-up recorded, not blocking

- `quality_audit/option_efficacy.py` re-raises the same 58 "NO EFFECT" rows every
  run because it does not model "the changed value equals the current value",
  "the value saturates past the data" or "this input form does not apply". A
  genuinely dead control would arrive as the 59th line of a list that is always 58
  long. Its existing `PRECONDITIONS` / `CONTROL_REQUIRES` tables could carry the
  four precondition pairs proved in `release_audit/v1.2.0/CONTROL_AUDIT.md`.
- A README note on macOS architecture (limitation 1).
