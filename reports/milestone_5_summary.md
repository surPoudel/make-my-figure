# Milestone 5 Summary — Complete example / template data system

Date: 2026-06-30

## What was built

A full, synthetic **example + template** system covering **all 17 plot types the
app supports**, integrated into both frontends.

### Generator
`scripts/generate_example_data.py` — reproducible (seed 42), synthetic, safe to
re-run, writes only inside `examples/`. Comments document the simulated
scenario per plot type. Produces per-plot folders, a combined workbook, and a
manifest.

### Files (`examples/`)
```
examples/
  example_data_manifest.json               machine-readable index (all fields)
  Make_My_Figure_All_Example_Data.xlsx     one sheet per plot type (+PCA metadata)
  by_plot_type/<slug>/
    data.csv  data.tsv  data.xlsx          same table, three formats
    plotspec.json                          ready-to-use PlotSpec
    README.md                              row/column meaning + how to replace + pitfalls
    metadata.* (PCA only)
```
17 plot types × (csv+tsv+xlsx+plotspec+README) + PCA metadata = 90 files, ~700 KB.

### Core loader + app integration
- `make_my_figure_core/examples.py` — manifest-driven loader (resource-path aware,
  works frozen). `load_example()` returns table + aux + PlotSpec.
- Desktop app: `controller.load_example`, `example_description`, `example_source_path`,
  and `save_template` now prefer the `examples/` system (mock_data fallback). “Open
  example” for every plot type; “Save template” exports csv/tsv/xlsx by extension.
- Streamlit app: “Use example data” now lists all 17 example plot types, shows the
  synthetic-scenario caption, and threads PCA metadata from the example automatically.
- PyInstaller spec bundles `examples/` so the packaged app has them too.

### Docs
- `docs/EXAMPLE_DATA.md`, `docs/DATA_TEMPLATES.md`, `docs/PLOT_TYPE_REQUIREMENTS.md`
  (per-plot required/optional columns, generated from the manifest). README links added.

## Synthetic-data & published-paper policy (stated in docs + manifest + every README)
> Published papers/figures are used only as visual **style references** (layout,
> typography, panels, legends, spacing). All bundled example datasets are
> **synthetic** (generated from code), not copied from any publication, and must
> not be cited as real biological findings.

- data_type: **synthetic**; license: **CC0-1.0**; source: **generated by
  `scripts/generate_example_data.py`**. No real datasets were added.

## Tests
`pytest -q` → **246 passed** (was 139). New `tests/test_examples.py` (107 cases)
verifies, for every supported plot type: example exists; CSV/TSV/XLSX load;
PlotSpec validates; required columns present; renders without error; exports
SVG/PNG/PDF + PlotSpec JSON; the combined workbook has all expected (≤31-char)
sheets; and the manifest is complete, synthetic, and CC0.

## Coverage
- **17 / 17 supported plot types** have example data. **None missing.**
- Requested types with **no renderer in the app** (so no example data): MA plot,
  UMAP/t-SNE, GSEA plot, precision-recall curve, histogram, correlation matrix,
  UpSet plot, Venn diagram. These can be added once their renderers exist.

## Regenerate

```bash
python scripts/generate_example_data.py
```
