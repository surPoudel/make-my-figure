## DESIGN

- **Name / extension:** *Reproducible figure package*, `.mmfpackage` (a ZIP container). Distinct from
  `.plot_spec.json` (recipe; data required) and `.mmfpreset.json` (appearance; no data).
- **Internal structure:** `manifest.json`; `plot_spec.json` + `stats_spec.json` (single) or `figure_spec.json` +
  `panels/<id>/{plot_spec,stats_spec,panel}.json` (composite); `matrix_spec.json`, `sample_metadata_spec.json`,
  `preprocessing_spec.json` when the plot came from the Matrix Workflow; `data/<table>.mmftable.json` (canonical),
  `data/<table>.csv` (human copy, ≤ 2 M cells), `data/original/<table>/<file>` (original CSV/TSV/XLSX when available,
  ≤ 512 MB); `assets/<panel>/<image>`; `preview/figure.{png,svg,pdf}`; `environment/environment.json`; `README.txt`.
  Identical tables are stored once (content digest).
- **Canonical data format:** `mmftable` v1 — JSON with per-column dtype records: float64 via shortest round-trip
  repr (bit-exact incl. NaN, ±Inf, −0.0), float32 widened/narrowed exactly, integers as JSON integers, nullable
  Int/boolean/string with `null`, categoricals with categories + order, datetimes/timedeltas as int64 ns (+ tz),
  object cells type-tagged. Deterministic bytes (sorted keys) → the file SHA-256 is a content digest. No new
  dependency. Verified bit-exact for 17-digit doubles, denormals, 1e308, Unicode, categories, dates, nullable types,
  a 20 000 × 41 and a 60 000-row table.
- **Manifest schema / version:** `schemas/figure_package_manifest.schema.json` (draft 2020-12), `package_format =
  make_my_figure.figure_package`, `format_version = 1`, `created_with {version, commit}`, `created_at`, `figure_kind`,
  `specs`, `components`, `tables` (role, path, sha256, bytes, shape, columns, dtypes, display name, original file,
  derived_from, provenance), `assets`, `previews`, `files` (integrity list), `relationships`, `environment`,
  `warnings`, `compatibility`, `privacy_notice`. Readers accept `SUPPORTED_FORMAT_VERSIONS = (1,)` and refuse newer
  versions with an explicit message.
- **Privacy:** both save dialogs state "Figure packages include the data required to reproduce the figure" with the
  full notice, list what goes in and the estimated size; the notice is repeated in README and manifest. Absolute
  original paths are **not** recorded (opt-in flag exists, off).
- **Security:** member-name validation (no `..`, absolute, drive, backslash, control chars), symlink/device rejection,
  caps on entries (5000), entry size (1 GiB), total (3 GiB), compression ratio (400×), manifest size; unlisted or
  altered files fail; JSON only; assets copied byte-for-byte under sanitised names; no pickle/exec (guarded by a test).
- **Statistics:** stored with results; on open recomputed from the frozen data and compared (test id, groups, n,
  statistic, P, adjusted P, effect size, CI) — differences are reported, never silently accepted.
- **Preprocessing:** source **and** derived tables frozen; the recorded chain is replayed on the frozen source and
  compared with the frozen derived table (exact, then 1e-10 relative); the figure is always drawn from the frozen
  derived table. `PreprocessingStep.user_parameters` was added so chains replay exactly (legacy records fall back to
  signature filtering).

## MANUSCRIPT (`reports/v1.1.1_manuscript_claim_audit.md`; manuscript NOT edited)

- **Too strong / false today:** "StatsSpec, PlotSpec, and FigureSpec are written alongside every export" (false);
  every "writes/written" for MatrixSpec, SampleMetadataSpec, PreprocessingSpec; "every export writes a sidecar";
  "the StatsSpec is written next to each export"; "records the source data" (it records the identity).
- **Becomes true after v1.1.1:** all of the above when phrased around the figure package; "neither interface reopens
  a FigureSpec" flips to "a composite reopens from a figure package in both interfaces".
- **Recommended wording after approval:** PlotSpec = machine-readable record of one plot (recipe; data required);
  Figure Preset = reusable configuration without data; Figure Package = portable artifact with the frozen data and
  every specification, verified by checksum. Sentence-level proposals are in the audit table.
