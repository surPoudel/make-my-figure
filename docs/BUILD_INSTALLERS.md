# Building Installers

Make My Figure desktop is packaged with **PyInstaller** into a standalone app
that bundles Python and all dependencies, so end users never install Python.

## Prerequisites

```bash
python3 -m venv .venv && source .venv/bin/activate   # (Windows: .venv\Scripts\activate)
pip install -e ".[desktop,build]"
python scripts/make_icons.py        # generate placeholder icons (once)
```

## One command (any OS): build the app

```bash
python scripts/build_desktop.py --clean
```

Output:
- Windows / Linux: `dist/MakeMyFigure/` (one-folder app; the launcher is
  `MakeMyFigure[.exe]` inside).
- macOS: `dist/MakeMyFigure.app`.

The PyInstaller config is `packaging/make_my_figure.spec`. It bundles the
`schemas/`, `style_profiles/`, `mock_data/`, and `assets/icons/` folders, which
the core resolves at runtime via `make_my_figure_core.resources` (uses
`sys._MEIPASS` when frozen).

## Per-OS installers

### Windows  (`scripts/build_windows.ps1`)
```powershell
.\scripts\build_windows.ps1
```
- Always produces `dist/MakeMyFigure-windows.zip` (portable).
- If **Inno Setup** (`iscc.exe`) is on PATH, also builds
  `dist/MakeMyFigure-Setup.exe` from `packaging/windows_installer.iss`.

### macOS  (`scripts/build_macos.sh`)
```bash
./scripts/build_macos.sh
```
- Generates `assets/icons/icon.icns` from the PNGs (via `iconutil`).
- Produces `dist/MakeMyFigure.dmg` (via `hdiutil`), or `MakeMyFigure-macos.zip`
  as a fallback.

### Linux  (`scripts/build_linux.sh`)
```bash
./scripts/build_linux.sh
```
- Always produces `dist/MakeMyFigure-linux.tar.gz` (portable).
- If `appimagetool` is on PATH, also builds `dist/MakeMyFigure.AppImage`.

## Expected release artifacts

| OS | Primary | Fallback |
|----|---------|----------|
| Windows | `MakeMyFigure-Setup.exe` | `MakeMyFigure-windows.zip` |
| macOS | `MakeMyFigure.dmg` | `MakeMyFigure-macos.zip` (zipped `.app`) |
| Linux | `MakeMyFigure.AppImage` | `MakeMyFigure-linux.tar.gz` |

## CI

`.github/workflows/build_desktop_releases.yml` builds all three on
`windows-latest`, `macos-latest`, and `ubuntu-latest` and uploads the artifacts.
It runs on a `v*` tag or manual dispatch and **does not** publish a public
release on its own.

## Icons

Placeholders live in `assets/icons/` (generated by `scripts/make_icons.py`).
To rebrand: replace `icon.png` (512×512 recommended) and re-run the script to
regenerate `icon.ico` and the sized PNGs; on macOS regenerate `icon.icns` via
`scripts/build_macos.sh` (uses `iconutil`).

## Notes / gotchas

- First launch of an **unsigned** app triggers OS security warnings — see
  [CODE_SIGNING.md](CODE_SIGNING.md).
- Builds are **not** cross-compilable: build each OS on that OS (or via CI).
- The app folder is large (~hundreds of MB) because it bundles Qt, NumPy,
  SciPy, and Matplotlib. This is expected for a zero-dependency installer.
