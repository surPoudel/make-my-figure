# Example / Template Data

Every plot type Make My Figure supports ships with a clean, realistic **synthetic**
example dataset you can open, preview, plot, export, and then replace with your own data.

> **Published papers and figures are used only as visual style references** for layout, typography, panel structure, legends, annotations, spacing, and general publication formatting. The bundled example datasets are **synthetic** unless explicitly marked otherwise. Synthetic examples are not copied from published papers and must not be cited as real biological findings.

## Provenance & license

- **Data type:** synthetic (generated by `scripts/generate_example_data.py`, fixed seed 42)
- **License:** CC0-1.0 (public domain dedication)
- **Source/provenance:** generated from code; not derived from any published dataset.

If a real open dataset is ever added, it must include citation, DOI/URL, license, date
accessed, exact source file, and transformation steps — and must be omitted if the
license is unclear.

## Where the files live

```
examples/
  example_data_manifest.json                  machine-readable index (all fields)
  Make_My_Figure_All_Example_Data.xlsx        one sheet per plot type
  by_plot_type/<slug>/
    data.csv  data.tsv  data.xlsx             the same table in three formats
    plotspec.json                             ready-to-use PlotSpec
    README.md                                 what each column means + how to replace
    (metadata.* for PCA)
```

## Regenerate

```bash
python scripts/generate_example_data.py
```

Safe to re-run; only writes inside `examples/`.

## Requested plot types not (yet) supported by the app

These have no renderer in the current app, so no example data is bundled:
**MA plot, UMAP/t-SNE, GSEA enrichment plot, precision-recall curve, histogram,
correlation matrix, UpSet plot, Venn diagram.** They can be added when their
renderers are implemented.

See also: [DATA_TEMPLATES.md](DATA_TEMPLATES.md), [PLOT_TYPE_REQUIREMENTS.md](PLOT_TYPE_REQUIREMENTS.md).
